# Contribution Guidelines

Thank you for your interest in contributing to the Government Scheme Matcher project!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/governmentschemematcher.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Run tests: `python -m pytest tests/`
6. Commit your changes: `git commit -m 'Add your feature'`
7. Push to your fork: `git push origin feature/your-feature`
8. Create a Pull Request

## Code Style

- Follow PEP 8 standards
- Use type hints in function signatures
- Add docstrings to all functions and classes
- Maintain existing code structure

## Testing

- Write tests for new features
- Ensure all tests pass before submitting PR
- Aim for >80% code coverage

## Reporting Issues

- Use the GitHub Issues tab
- Provide clear description and steps to reproduce
- Include relevant error messages and logs

## Questions?

Create a discussion or open an issue for questions and suggestions.
